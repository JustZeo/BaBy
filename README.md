# 🌙 Baby

> A cozy pixel-art companion app for supportive boyfriends — track her cycle, remember what she loves, and never miss a moment that matters. 💌

100% offline · Zero trackers · Zero cloud · Just you, her, and a pixel cat 🐱

---

## ✨ Features

- 🩷 **Cycle Tracker** — log flow, mood, symptoms, and health notes day by day
- 📅 **Pixel Calendar** — a color-coded calendar so you always know what phase she's in
- 📊 **Analytics** — cycle trends, mood charts, and symptom correlations, all computed on-device
- 💎 **Memories** — save her favorites: coffee order, sizes, flowers, important dates, the little things
- 📓 **Journal** — jot down date ideas, gift ideas, and sweet moments to look back on
- 🐾 **Pixel Pet Companion** — level up, earn Love XP, and unlock cozy room decorations by showing up for her
- 🔔 **Offline Reminders** — gentle local notifications, no internet required
- 🔒 **100% Private** — everything is stored locally on your device. No accounts, no analytics, no data ever leaves your phone

---

## 🛠️ Built With

- [Expo](https://expo.dev) + React Native
- TypeScript
- React Navigation
- AsyncStorage (local JSON storage)
- React Native SVG / Reanimated for the pixel-art UI

---

## 🚀 Running Locally

```bash
# 1. Clone the repo
git clone https://github.com/JustZeo/BaBy.git
cd BaBy

# 2. Install dependencies
npm install

# 3. Start the app
npm run start
```

Then run it on Android/iOS with:

```bash
npm run android
# or
npm run ios
```

---

## 🔐 Privacy

Baby stores **100% of your data locally** on-device via AsyncStorage — there are no servers, no accounts, and no analytics SDKs. Nothing you log ever leaves your phone.
